the conditional theorem that every model supplying those fields yields that certificate;

Not kernel-checked: the semantic content and external-artifact correspondence of C*, E*, P*, machinery closure, commitment equivalence, W7–W14, the actual RCCD package construction, and the quantified theorem over arbitrary admissible representation R.

Frozen canonical assurance statement: the project-status surface says the composition is executable and audited but is not one kernel-checked proof object.

Terminal theorem’s own mechanism record: single_kernel_checked_semantic_terminal_theorem is false.

Thus the frozen terminal theorem has heterogeneous/mixed assurance: conditional theory statements plus executable witnesses and checker bookkeeping, but not a faithful end-to-end kernel derivation. The accepted proof-status register states exactly that.

The case succeeds only as a partial formalization, not as G1/OP-06 closure.

The issue is not that premises are assumed. Conditional premises are legitimate.

The issue is that Lean does not state the same premises. inTargetClass : Source → Prop does not formalize C*; admissible : Package → Prop does not formalize E*; an eight-label vector does not formalize P*; and the five unary source predicates do not state W7–W11.

Quantifier mismatch is material. The canonical theorem quantifies over every source S and qualified representation R. The Lean terminal theorem quantifies only over source and discusses the single stipulated encode source.

Witness mismatch is material. Canonical necessity and sufficiency propositions existentially require effective domains, relations, traces, an RCCD package, and reconstruction maps. Lean replaces them with arbitrary unary predicates and pre-existing functions.

Independence mismatch is decisive. A Boolean/unary assertion named componentIndependent does not encode five separating witnesses or failure of reductions.

Maximality mismatch is decisive. No registered rule or challenge ledger exists in Lean.

The countermodel proves the interface’s semantic unconstrainedness. An instance sets substantive predicates to True and proves their fields trivially.

Names can be replaced without affecting the theorem. This establishes that kernel correctness is parametric logical bookkeeping, not semantic assurance.

No canonical authority declares this abstraction level sufficient. The accepted registers instead preserve OP-06, UQ-T3, and LIM-007 as open.
