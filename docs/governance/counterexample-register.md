# Counterexample Register

Status: **Accepted red-team register**

These are threats, not claims that a counterexample has already refuted the bounded terminal theorem.

| Class | Threatened claim | Representability / expressive-loss risk | Hidden assumption / disposition |
|---|---|---|---|
| formal logic, type theory, proof theory | primitive sufficiency | proof identity, binding, judgmental equality may be flattened | explicit syntax/semantics assumed; unresolved globally |
| Bayesian reasoning, causal inference, probabilistic programming | discrete architecture/general translation | measures, conditioning, interventions, continuous distributions may become opaque derived machinery | finite/discrete encodability assumed; open |
| model-based reasoning, scientific modeling | preservation/completeness | idealization, approximation and model-world correspondence can be lost | explicit representability assumed; open |
| argumentation and legal reasoning | admissibility universality | burdens, defeaters, precedent and institutional authority may not reduce without extra commitments | fixed criteria assumed; bounded mappings only |
| category theory | object/relation vocabulary sufficiency | morphism-first and higher coherence structure may be distorted | object-centric reading is not mandatory but equivalence unproved |
| machine-learning workflows | common architecture | learned continuous state and opaque updates resist auditable reconstruction | explicit finite artifact assumed; open |
| self-modifying/changing-rule systems | fixed calculus sufficiency | rule provenance and meta-level change can escape a fixed transition schema | frozen rule universe assumed by bounded results |
| nonmonotonic/paraconsistent reasoning | classical preservation | retraction, defeasibility and non-explosion can be erased by classicalized mappings | monotonic/consistent semantics must not be presumed |
| embodied/sensorimotor reasoning | representation universality | continuous coupling and tacit skill may lack faithful explicit representation | reasoning-as-explicit-artifact assumption threatened |
| open-ended design/aesthetic judgment | admissibility and resolution | criteria can emerge, conflict, or remain non-decidable | fixed objective/termination assumed; open |
| practical deliberation | comparison/dominance | incommensurable values and changing preferences block Pareto conclusions | stable dimensions assumed; protocol-relative only |
| incompatible ontologies | lossless translation | no shared commitment-equivalent target may exist | common ontology/canonicalization assumed; failure must be reported |
| W3 oracle-paired executions (`CE-W3-001`) | lossless universal reconstruction from explicit internal state alone | identical internal state and trace receive different external oracle truth values, so one internal reconstruction cannot preserve both | valid counterexample to the internal-state-only form; adding oracle identity/transcript is charged auxiliary machinery, not a repair of the refuted claim |
| W3 concurrent independent events (`CE-W3-002`) | unique total-trace common architecture | either linearization invents historical order; partial-order/event-structure encoding is a materially different reconstruction | refutes uniqueness and leaves total-trace historical preservation unresolved |
| W4 identity/causal/history collisions | exact recovery and semantic equivalence | ontology quotient, observational causal projection, merge, and final-state projection map inequivalent sources to one target | `FARA-W4-PROOF-001` establishes bounded recovery failures; narrowed behavior cannot repair the collision |
| W4 oracle/embodiment/continuous cases | machinery-closed losslessness | replay requires a live oracle, body/environment, or infinite-precision content absent from the archive | hidden machinery or finite approximation must be disclosed; general status remains unresolved |
| W5 attempted cross-representation witnesses (`CE-W5-001`–`CE-W5-005`) | representation-independent FAR/FARA conclusions | loss, collapse, partial-order linearization, decoder-smuggling, and circular equivalence can produce apparent conclusion differences | none is an admissible same-source, exact-recovery, all-six-preserving counterexample; they remain rejected attempts or representation-boundary witnesses and do not refute invariance |

No row currently justifies a new primitive. Each instead blocks global claims until a registered construction, reduction, or counterexample adjudication exists.
| FARA vocabulary collapse witnesses (`CE-VOC-001`–`CE-VOC-004`) | non-vacuous expressive coverage | intervention/correlation, proof/proposition identity, partial/total order, and semantic-version/decoder pairs collapse when catch-alls replace exposed roles | retained by `FARA-VOC-PROOF-001`; bounded to the frozen interpretation |
| multi-extension admissibility semantics (`CE-ADM-001a`, `CE-ADM-001b`) | sufficiency of `Ω`'s canonical per-candidate classification form | set-valued admissibility is not recoverable from a per-candidate map: a two-cycle argumentation framework has two preferred extensions whose joint inadmissibility is unrepresentable, and a self-attacking argument has no stable extension, so multiplicity and nonexistence collapse to one recorded status | retained by `docs/research/fara-admissibility-priority-v1.0.md`; bounded to multi-extension semantics and witnessed by Dung 1995 preferred/stable semantics. Grounded semantics map without loss. Does not refute calculus-determined admissibility, does not indicate a sixth primitive, and does not bear on the terminal UPP theorem or its frozen `E*` premise. **Strengthened 2026-08-10** by `docs/research/fara-omega-set-valued-admissibility-v1.0.md`: the loss is not specific to these witnesses but holds for every function `C → Status`, by equivariance pigeonhole.
