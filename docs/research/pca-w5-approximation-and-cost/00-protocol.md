# PCA-W5 Approximation and Cost Protocol

Status: **Accepted bounded execution protocol**

## Question

Can W5 operationalize approximation and implementation cost without importing an implicit scalar objective, unique optimum, or semantics from W4?

## Execution

Freeze a finite binary control before evaluation. Declare a separating 0/1 metric, decision loss, uniform reference mass, expected aggregation, tolerance `1/2`, randomized decoders, and two independent cost coordinates. Recompute all tables with exact rational arithmetic. Mutate each semantic dependency and require rejection. Repeat with zero tolerance. Adversarially mutate required-behavior and representation status, freeze status, zero-mass reference support, campaign manifest record/artifact enumeration, and verifier/checker bindings. Check the two-coordinate incomparability and zero-sum boundary in Lean using the pinned toolchain in the dedicated W5 workflow.

## Falsifiers

Reject terminal completion if any accepted checked record permits a non-explicit required behavior or representation, a non-frozen checked contract, an incomplete/non-probability reference or decoder, invalid metric, incomplete loss, undeclared aggregation, unbound tolerance, incomplete cost vector, false feasible/frontier/least/exact claim, modified frozen contract, incorrect zero-mass support inference, silent scalarization, vacuous campaign enumeration, or an unbound semantic verifier/campaign checker. Preserve `Unknown` outside the finite-explicit scope.

## Scope

For expected aggregation, exact recovery is evaluated on positive reference support; for maximum aggregation it is evaluated on every listed source case. The registered zero-tolerance control has positive mass on every case, so its full-domain exact boundary is unchanged.

This is a constructed semantic control, not a continuation or reinterpretation of any W4 domain result. W4 supplies no approximation choice. W6 empirical utility is excluded.
