# PCA-W5 Approximation and Cost Protocol

Status: **Accepted bounded execution protocol**

## Question

Can W5 operationalize approximation and implementation cost without importing an implicit scalar objective, unique optimum, or semantics from W4?

## Execution

Freeze a finite binary control before evaluation. Declare a separating 0/1 metric, decision loss, uniform reference mass, expected aggregation, tolerance `1/2`, randomized decoders, and two independent cost coordinates. Recompute all tables with exact rational arithmetic. Mutate each semantic dependency and require rejection. Repeat with zero tolerance. Check the two-coordinate incomparability and zero-sum boundary in Lean when the pinned Lean executable is available.

## Falsifiers

Reject terminal completion if any accepted record permits an incomplete/non-probability reference or decoder, invalid metric, incomplete loss, undeclared aggregation, unbound tolerance, incomplete cost vector, false feasible/frontier/least/exact claim, modified frozen contract, or silent scalarization. Preserve `Unknown` outside the finite-explicit scope.

## Scope

This is a constructed semantic control, not a continuation or reinterpretation of any W4 domain result. W4 supplies no approximation choice. W6 empirical utility is excluded.
