## Objective

Independently motivate exact comparison contracts for formal logic, Bayesian/causal reasoning, argumentation, model-based reasoning, type theory, and proof theory. Only after a native-domain account is frozen may it be mapped into `far-ir/2.0` and tested for finite-explicit factorization or collision.

W4 asks whether explicitly chosen representations preserve behavior under each frozen, domain-native contract. It does not ask whether one contract, representation, equivalence, or architecture is universal.

## Staged access

### Stage A — native discovery

Use only the queries frozen in `research/campaigns/pca-w4-domain-contracts-v1.0.json`. Queries contain no Project FAR terminology. Discover sources through Consensus, SciSpace, Scite, Acumen/Talarion, and ordinary web research. Zotero is the intended bibliographic-identity lane. Record every invocation, failure, result admitted to the corpus, and rejection reason.

Prohibited during source selection: Project FAR mappings, candidate W4 examples, `far-ir/2.0` field names, and conclusions that a source supports Project FAR.

### Stage B — primary-source verification

Verify bibliographic identity and the exact native definitions of cases, behavior, observation, equivalence, transformation, or judgment. Prefer primary papers, monographs, standards, and official technical documentation. Discovery-system summaries and citation labels are leads, not evidence.

Freeze one native-contract memo per domain before mapping. Preserve disagreements and mark absent or inaccessible source support `Unknown`.

### Stage C — controlled FAR mapping

Map each frozen native contract to the mandatory `far-ir/2.0` dimensions. Construct bounded finite examples only where every case, behavior value, and representation value is explicit. A checked result certifies the encoded table property only.

For each domain, test both:

1. a deliberately lossy representation expected to expose a consequence-affecting collision; and
2. an explicit repaired representation expected to factor the same bounded behavior.

The repair is a scoped sufficiency witness, not a claim of minimality, naturalness, uniqueness, efficiency, or domain completeness.

### Stage D — hostile audit and promotion gate

Run schema validation, semantic recomputation, mutation controls, source-manifest validation, contract-freeze checks, documentation/governance checks, and the full repository suite. Recheck external-domain correspondence independently of table validity. Preserve `Unknown`, negative results, tool failures, and rejected sources.

## Nonclaims

This campaign cannot establish novelty, priority, open-domain universality, contract-free minimality, empirical utility, computational efficiency, or product readiness. A finite collision refutes only the recorded candidate representation under the frozen contract. A finite factorization proves only the recorded decoder over the recorded cases.
