# FAR-SAT-v0.4 Repository Replication

Status: Replicated internally  
Scope: representational-gap replication, not external empirical validation

## Objective

Re-run the necessity test using canonical repository artifacts rather than the harvest narrative.

## Procedure

1. Treat canonical schemas and methodology as controlling.
2. Search for structured fields/objects representing:
   - source copying/common-origin/independence;
   - valid-time versus known/recorded-time;
   - deliberate machine abstention with reason;
   - required self-assurance dimensions;
   - hostile-source/data-control boundary.
3. Search for nearby existing mechanisms that could reduce each candidate.
4. Reject any proposed primitive that can be represented without loss by an existing typed contract.
5. Record unresolved ambiguity rather than inferring absence from naming alone.

## Replicated observations

- Intake already contains search stopping/saturation machinery, so no duplicate search-control primitive is required.
- Evidence adjudication contains `unresolved`, but its contract boundary identifies it as a human/policy adjudication record and does not type machine abstention causes.
- The knowledge graph contains typed source/evidence/argument entities and relations, but does not require common-origin or copying lineage.
- No canonical field found establishes valid-time/known-time separation.
- Existing graph vocabulary can express assurance claims, but no audit-completion contract requires assurance dimensions.
- No canonical policy found grants source content a dedicated untrusted-data boundary.

## Replication result

The same four representational gaps and one security boundary survive the second repository-first pass.

## Limits

This replication establishes a repository-contract gap, not empirical superiority of the proposed representations. External benchmarking remains separate work.
