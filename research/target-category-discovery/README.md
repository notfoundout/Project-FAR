## Purpose

This directory separates two tracks:

1. an internal scoped theorem about functor-invariant operations on small categories;

Neither track changes accepted Project FAR theory.

## Scoped compositional result

For a fixed finite input graph, every finitary arrow-valued operation invariant across all small categories and all functors is evaluation of one unique path in the free category. Conversely, every fixed path defines such an operation.

The path language is generated by identities and typed sequential composition. In the committed `A->B->C` fixture, `b∘a:A->C` is the nontrivial invariant witness. Identity is not a nontrivial witness and is not even type-admissible for the distinguished `A->C` output shape.

The result is internal Research. The legacy report path is retained for compatibility, but theorem release is blocked because `RG-07 nonclaim-audit` remains unsatisfied.
