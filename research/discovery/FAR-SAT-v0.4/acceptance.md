# FAR-SAT-v0.4 Acceptance Record

Status: Accepted  
Scope: bounded representational requirements

## Accepted discoveries

The following requirements survived execution, reduction, falsification, and repository-first replication:

1. Source dependence must be representable independently of source count.
2. Valid-world time must be representable independently of FAR knowledge/record time.
3. Deliberate abstention must be representable independently of unresolved adjudication.
4. Completed audits must carry a typed self-assurance profile.
5. Source material under audit is untrusted data and has no control authority.

## Promotion decision

Promote these requirements as composable v1 contracts and semantic validators.

Do not:
- mutate existing v1 contracts incompatibly;
- add forecast/commitment contracts yet;
- add a second general-purpose knowledge graph;
- duplicate existing intake saturation/search fields;
- claim external empirical validation.

## Falsification condition after promotion

If the promoted contracts introduce distinctions that are not exercised by tests, can be losslessly reduced to existing fields, or create incompatible duplicate authority, revert or consolidate them.
