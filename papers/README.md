# Papers

## Purpose

This directory contains formal papers derived from Project FAR.

Papers present mature portions of the framework intended for publication or public distribution.

Unlike the research directory, papers should reflect stable developments of the theory.

## Authority boundary

Papers are downstream syntheses, not canonical definitions or prerequisites. When paper language conflicts with a canonical status or scope, the [canonical map](../docs/CANONICAL_MAP.md), [terminology authority](../docs/glossary/canonical-terminology.md), and source proof/evidence record control.
